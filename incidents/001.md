# 001. A path through `..` was treated as allowed

The first checker, commit `267c806`, compared the raw path to the forbid list. `src/` is not on that list, so `src/../README.md` was allowed. After the `.` and `..` are collapsed, that path is `README.md`, which the implement card forbids.

Commit `bf96736` rejects three cases the first version missed:

- `samples/escape.diff` hides `README.md` behind `src/..`
- `samples/outside.diff` writes `../secrets.env` outside the tree
- `samples/cards.diff` rewrites `cards/implement.md` and deletes the forbid line

The eval table in `docs/EVALS.md` locks the expected text. `python src/fence.py report` prints the denominator: 6 cases, and a non-zero exit if any case drifts.
